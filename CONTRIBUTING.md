# Contributing to SipoDeck

Thanks for your interest in contributing to SipoDeck!

SipoDeck is an open-source macro deck platform built around ESP32 hardware and a Windows desktop application.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Make your changes.
5. Test your changes.
6. Commit your changes with a clear commit message.
7. Open a Pull Request.

## Development Guidelines

* Keep changes focused and avoid unnecessary refactoring.
* Follow the existing project structure and conventions.
* Do not commit passwords, API keys, tokens, private URLs, or other sensitive information.
* Keep ESP32 firmware and Windows application responsibilities separated.
* New integrations should use the plugin system when appropriate.
* Document significant architectural changes.

## Pull Requests

Pull Requests should include:

* A clear description of the change.
* The reason for the change.
* Testing information.
* Screenshots or other relevant information when UI changes are involved.

## Issues

Before opening an issue, check whether a similar issue already exists.

For feature requests, explain the problem you are trying to solve rather than only describing the requested implementation.

## Code of Conduct

Please be respectful and constructive when interacting with other contributors.
